# Lyctor
Lyctor is a julia package for working with skeletal fusion categories. It is meant to be an open source and free replacement of Anyonica (in the future). It is still in heavy development and should be used with great care as long as its version does not reach 1.0. 

## The name
The name Lyctor (LICK-tor) comes from the book series of the Locked Tomb. It is an undying necromancer of the highest order.
